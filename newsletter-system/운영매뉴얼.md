# 방산MICE 글로벌 방산뉴스 — 일일 운영 매뉴얼

매일 아침 **약 30~40분**이면 1개 호를 발행할 수 있도록 만든 파이프라인입니다.

---

## 매일 아침 3단계

### 1단계 — 수집 (자동, 약 40초)

`1_수집.bat` 더블클릭 (또는 아래 명령)

```bash
python system/collect.py --days 3
```

- 공식 조달포털 + 전문매체 + 구글뉴스 타깃쿼리를 동시에 긁어옵니다.
- 최근 3일 이내 항목만 남기고, **과거 발행분과 중복되는 건은 자동 제외**합니다.
- 자동 사전채점(0~100점)으로 정렬합니다.

생성물
| 파일 | 용도 |
|---|---|
| `data/raw/YYYY-MM-DD.json` | 원자료 전체 (기계 판독용) |
| `data/raw/YYYY-MM-DD_digest.md` | **편집자가 읽는 다이제스트** (상위 80건, 국내/해외 표시) |
| `data/seen.json` | 30일치 중복방지 목록 |
| `data/sam_cache/` | SAM.gov 응답 원본 (필터 수정 시 재호출 없이 검증용) |
| `data/sam_calls.json` | SAM.gov 당일 호출 수 |

### 2단계 — 편집 (사람, 20~30분)

`data/raw/YYYY-MM-DD_digest.md`를 읽고, 발행할 건을 골라
`data/edition/YYYY-MM-DD.json`을 작성합니다.
직전 호(`data/edition/2026-08-24.json`)를 복사해 내용만 바꾸는 방식이 가장 빠릅니다.

**이 단계가 이 서비스의 전부입니다.** 수집은 누구나 할 수 있고, 여기서 차별화가 생깁니다.
모든 기사는 다음 4개 질문에 답해야 합니다.

1. 한국 기업에 왜 중요한가 → `why`
2. 어떤 기업·기술에 기회가 있는가 → `targets`
3. 지금 무엇을 준비해야 하는가 → `action`
4. 누구와 연결할 수 있는가 → `action` 내 무역관·파트너 항목

### 3단계 — 링크 검증 + 메일/웹 생성 (자동)

`2_메일생성.bat` 이 **검증 → 생성** 순서로 자동 실행합니다.

```bash
python system/verify.py     # 링크 검증
python system/render.py     # 메일 + 웹 생성
```

**검증기는 반드시 통과시키고 발행하십시오.** 다음을 잡아냅니다.
- 터미널에서 URL을 복사하다 **잘린 주소** (실제로 이 사고가 있었습니다)
- 공고번호를 잘못 적은 링크
- 죽은 링크 · 삭제된 공고

판정 방식은 2단계입니다.
1. 그날 수집 원자료에 있는 URL이면 즉시 통과 (수집기가 실제로 가져온 링크이므로)
2. 원자료에 없으면 실제 접속해 응답 확인 → **손으로 옮겨 적은 링크만 실측**

> 편집할 때 **URL은 직접 타이핑하지 말고 반드시 `data/raw/YYYY-MM-DD.json` 에서 복사**하십시오.
> 다이제스트(`_digest.md`)의 링크는 잘리지 않은 전체 주소입니다.

### 3-1단계 — 생성물

두 개가 동시에 만들어집니다.

| 파일 | 용도 | 탭 |
|---|---|---|
| `05_콘텐츠/발행/YYYY-MM-DD.html` | **메일 발송용** | 탭 대신 상단 목차 + 순차 배치 |
| `05_콘텐츠/발행/YYYY-MM-DD_web.html` | **홈페이지 게시용** | CSS 전용 탭(JS 없음) |

메일 클라이언트는 `<style>`과 JS를 제거하므로 메일에서는 탭이 동작할 수 없습니다.
그래서 메일용은 상단에 목차(앵커 링크)를 넣고 두 탭을 이어서 배치하고,
탭 전환이 필요한 웹 게시용을 별도 파일로 만듭니다.

발송 방법
- **Stibee·메일침프**: `YYYY-MM-DD.html` 내용을 HTML 편집기에 붙여넣기
- **Gmail·아웃룩**: 브라우저로 연 뒤 전체복사(Ctrl+A → Ctrl+C) 후 메일 본문에 붙여넣기
- **홈페이지**: `_web.html`을 그대로 업로드하거나 본문에 삽입

## 편집본(edition JSON) 작성 규칙

```jsonc
{
  "date": "2026-08-24",
  "issue": 1,
  "subject": "메일 제목 - 가장 중요한 2건을 제목에 넣는다",
  "preheader": "메일 미리보기 한 줄",
  "lead": "오늘의 핵심 2~3문장 (<b>강조</b> 태그 사용 가능)",
  "stats": {"원시": "401건", "본 호 수록": "18건"},
  "sections": [ ... ]
}
```

### 탭 구조

편집본은 `tabs` 배열을 가지며, 각 탭 안에 섹션이 들어갑니다.

```jsonc
"tabs": [
  {"id":"intel", "label":"글로벌 마켓 인텔리전스", "desc":"탭 설명", "sections":[ ... ]},
  {"id":"scrap", "label":"방산 아티클 스크랩",     "desc":"탭 설명", "sections":[ ... ]}
]
```

섹션은 4가지 형식 중 하나입니다.

| kind | 용도 | 필수 필드 |
|---|---|---|
| `feature` | 긴급·핵심 기회 (하루 2~4건) | `title` `facts` `why` `targets` `action` `source` `url` `grade` `score` `tags` |
| `table` | 조달공고 목록 (하루 5~10건) | `country` `title` `note` `stage` `deadline` `url` (`urgent:true` → 마감일 빨간색) |
| `brief` | 시장동향·K방산 (하루 4~8건) | `title` `note` `source` `url` |
| `scrap` | 아티클 스크랩 | `items`(수동) 또는 `auto`(자동 채움) |
| `calendar` | 전시회·MICE 캘린더 | `auto: {months, limit}` — `data/exhibitions.json`에서 자동 |

### 전시회 캘린더 (`data/exhibitions.json`)

발행일 기준으로 **이미 끝난 전시회는 자동 제외**되고 다가오는 순으로 정렬되며 D-day가 계산됩니다.
D-30 이내는 빨강, D-90 이내는 주황으로 표시됩니다.
매일 손댈 필요 없이 **전시회가 새로 확정될 때만** 이 파일에 한 줄 추가하면 됩니다.

```jsonc
{
  "name_ko": "MSPO 2026 제34회 국제방위산업전시회",
  "name": "MSPO 2026",
  "country": "폴란드", "city": "키엘체(Kielce)",
  "start": "2026-09-08", "end": "2026-09-11",
  "focus": "지상장비·탄약·병사체계",
  "why": "왜 우리 기업이 가야 하는가 — <b>강조</b> 사용 가능",
  "url": "https://www.targikielce.pl/en/mspo",
  "verified": true,                    // false면 D-day 대신 '일정 미확정' 표시
  "note": "확정 안 된 부분을 여기에 적으면 주황 박스로 표시됨",
  "skip_verify": "접속 차단 등 링크 검증을 건너뛸 사유"
}
```

**중요**: 일정을 추측으로 채우지 마십시오. 확인되지 않았으면 `verified: false` + `note`에 상태를 적습니다.
국가관·공동관 신청은 통상 **개최 4~6개월 전에 마감**되므로 D-180 시점부터 검토가 필요합니다.

### 스크랩 섹션 — 자동 채움

`auto`를 지정하면 그날 수집한 원자료에서 자동으로 채웁니다. **국내 기사는 손댈 필요가 없습니다.**

```jsonc
{"kind":"scrap", "title":"국내 방산 아티클",
 "auto": {"region":"국내", "limit":22, "show_snippet":false}}
```

| 옵션 | 설명 |
|---|---|
| `region` | `"국내"` 또는 `"해외"` |
| `limit` | 최대 건수 |
| `show_snippet` | 요약 스니펫 표시 여부 |
| `include_tender` | 조달공고도 포함할지 (기본 제외 — 1번 탭과 중복되므로) |

- 앞 탭에서 이미 쓴 기사는 **자동으로 제외**됩니다.
- 여러 매체가 같은 사안을 보도한 경우 대표기사 1건만 나오고, 아래에 **"같은 사안 보도: 매체A · 매체B"** 링크가 붙습니다.
- 정렬 기준은 `보도 매체 수 → 점수 → 출처 등급` 입니다.

**해외 스크랩은 수동 작성을 권합니다.** 영문 제목만 나열하면 읽히지 않습니다.
`items`에 한국어 제목을 쓰고 `title_orig`에 원제를 넣으면 두 줄로 함께 표시됩니다.

```jsonc
{"title":"미 해군, 전 세계 연료 인프라 계약 약 10억 달러 발주",
 "title_orig":"U.S. Navy awards nearly $1B contract for global fuel infrastructure",
 "outlet":"Defence Blog", "date":"2026-08-22",
 "note":"한 줄 해설 — 왜 국내 기업이 볼 만한가",
 "url":"https://..."}
```

### 원문 링크 원칙

모든 항목은 **제목 자체가 링크**이고, 우측에 **별도 원문 버튼**이 붙습니다.
모든 링크는 `target="_blank"`로 새 창에서 열립니다.
구글뉴스 경유 링크는 클릭 시 해당 매체 기사로 바로 이동하며, 목적지를 알 수 있도록 **매체명을 함께 표기**합니다.
`url`이 없는 항목은 만들지 마세요.

`why` / `note` / `targets` / `action` 안에서는 `<b>`, `<br>` 사용 가능합니다.
`title`과 `facts`의 좌측 항목명은 자동 이스케이프되므로 태그를 쓰지 마세요.

### 정보 신뢰등급 (`grade`)
| 등급 | 기준 |
|---|---|
| A | 해외 정부·군·조달기관 공식자료 (TED, DoD, MOD 등) |
| B | 기업 공식발표 · KOTRA · 무관 확인 |
| C | 복수 전문매체 보도 |
| D | 단일 매체·현지 업계 제보 |
| E | 미확인 — **외부 발행 금지** |

수치가 매체마다 다르면 억지로 하나를 고르지 말고
"매체별로 4,000억~4,150억원으로 보도돼 확정되지 않았다"처럼 **불확실성을 그대로 적고 등급을 C로** 내립니다.
한 번의 오보가 신뢰도를 소멸시킵니다.

## 소스 추가·삭제

`system/sources.json` 하나만 고치면 됩니다.

- `rss` — 일반 RSS/Atom 피드. `tier` 1=공식, 2=전문매체
- `google_news` — 구글뉴스 검색 쿼리. **OEM·국가·품목을 늘리려면 여기에 한 줄 추가**
- `ted` — EU 공공조달. `cpv_prefixes`로 품목군 조절
- `scoring` — 자동 채점 키워드와 가중치

예: 브라질 시장을 추가하려면
```json
{"label": "브라질", "q": "Brazil defence procurement (tender OR acquisition OR contract)"}
```

### 중동·인도는 왜 매체 중심인가

두 지역 모두 **기계판독 가능한 공개 조달 API가 없습니다.**
사우디 Etimad·UAE 조달포털은 로그인/아랍어 기반이고, 인도 eProcure·GeM은 외부 접근이 막혀 있습니다.
그래서 이 지역은 **전문매체 + 종합지(방산 필터) + 타깃 검색어**로 신호를 잡고,
확정 정보는 KOTRA 무역관·현지 에이전트로 검증하는 구조가 현실적입니다.

중동은 특히 **현지화(로컬 콘텐츠)·합작·절충교역**이 진입 조건이므로,
단순 조달공고보다 "누가 어디에 합작법인·정비거점을 세우는가"가 더 중요한 신호입니다.
쿼리도 그렇게(사우디 GAMI/SAMI, UAE EDGE/Tawazun, 현지화·JV·오프셋) 구성했습니다.

### 품질 관리 장치
- **블록리스트** — `blocklist_outlets`(기계번역·수집형 사이트), `blocklist_title_kw`(주가·사건사고 등) 제외
- **유사기사 군집화** — 같은 사안을 다룬 기사를 묶어 대표기사 1건 + 타 매체 링크로 정리
- **대표매체 우선순위** — `preferred_outlets`에 등록된 매체를 대표기사로 선정
- **낱말 단위 채점** — 키워드를 단순 포함으로 검사하면 오탐이 난다.
  실제로 `oman`이 **R-oman-ia**에, `india`가 **Indiana**에 걸리는 문제가 있었다.
  지금은 앞뒤에 영문자가 붙지 않는 경우만 인정한다(`kw_match`).
- **종합지 필터** — `filter_kw`가 지정된 피드는 방산 키워드가 있는 기사만 수집한다.
  중동 종합지처럼 하루 100건씩 쏟아지는 피드를 붙일 때 필요하다.

### SAM.gov (미국 연방조달) 연동 — 키만 넣으면 작동

코드는 이미 붙어 있습니다(`system/sam.py`). **API 키만 넣으면** 자동으로 함께 수집됩니다.
키가 없으면 조용히 건너뛰므로 지금 상태로도 아무 문제 없습니다.

**1) 키 발급 (약 10분, 무료)**
1. <https://sam.gov> → 우측 상단 **Sign In** → **Create an Account** → **Personal Account**
2. Login.gov 계정 생성 (이메일 인증 + 2단계 인증 필수). 사업자 등록(UEI)은 **불필요**
3. SAM.gov 재로그인 → 우측 상단 이름 클릭 → **Account Details**
4. 페이지 하단 **Public API Key** 영역에서 계정 비밀번호 입력 → **Request API Key**
5. 키는 **화면을 벗어나면 다시 볼 수 없으므로 즉시 복사**

**2) 키 등록**
`system/secrets.example.json` 을 같은 폴더에 `secrets.json` 으로 복사하고 키를 붙여넣습니다.

```json
{ "sam_api_key": "발급받은키" }
```

`secrets.json` 은 **외부에 공유하지 마세요.** (환경변수 `SAM_API_KEY` 로 넣어도 됩니다)

**3) 점검**
```bash
python system/sam.py
```
키 인식 → 실제 호출 → 국방 관련 공고 상위 15건을 출력합니다.

**★ 호출 한도 주의**
개인(비연방) 계정은 **하루 10회** 요청 제한입니다. 사업자 등록(UEI) 계정은 1,000회입니다.
그래서 기본 설정은 공고유형 2종(사전수요조사·사전공고) × 최대 2페이지 = **하루 최대 4회**로 잡았고,
`data/sam_calls.json` 에 당일 호출 수를 기록해 `daily_call_budget`(기본 8) 초과 시 자동 중단합니다.
점검 명령도 호출을 소비하므로 **하루에 점검 1~2회 + 수집 1회** 정도로 쓰십시오.

수집 범위를 넓히려면 `sources.json` 의 `sam.ptypes` 에 추가합니다.
`o`=입찰공고, `k`=통합공고, `a`=낙찰공고. 단 **항목 하나당 하루 호출이 늘어납니다.**

국방 관련 판정은 **PSC(제품·용역 분류코드) 상위 2자리** 또는 **발주기관명**으로 합니다.
`psc_prefixes`: 10 무기 · 13 탄약 · 14 유도탄 · 15~17 항공 · 19~20 함정 · 23~25 차량 · 58 통신전자 · J0 정비용역 등

### 주요국 조달포털 (API 키 불필요, 이미 작동 중)

`system/portals.py` — 점검은 `python system/portals.py`

캐나다는 국방부(DND) 공고가 상시 150건 이상 열려 있어 안정적입니다.
빅토리아급 잠수함 예비품(소나·수중청음기), 차량 부품, 통신장비 등이 실제로 잡힙니다.
국방부 공고는 CSV에 직접 링크가 없어 **공고번호 검색 주소**로 연결합니다.

영국은 국방 비중이 낮습니다(3일간 439건 중 4건). 그래도 국방부·잠수함사업단(SDA)·Dstl 공고가
여기로 나오므로 유지합니다.

**폴란드를 끈 이유** — 검증해보니 폴란드 국내포털의 방산 공고는 대부분 **TED 재게재분(중복)**이고,
국내 전용 공고는 부대 급식·시설·도로공사가 대부분이었습니다.
K2·K9 같은 대형 사업은 군비청(Agencja Uzbrojenia)이 TED로 공고하므로 EU 수집기가 이미 잡습니다.
`sources.json` 의 `portals.poland.enabled` 를 `true` 로 바꾸면 즉시 다시 동작합니다.

## 저작권·법적 준수 (반드시 지킬 것)

- 수집기는 **제목·피드가 공개한 요약·URL·발행일만 저장**하며 기사 본문을 저장하지 않습니다.
- 유료·로그인 콘텐츠는 수집하지 않습니다. 전문매체는 **이슈 탐지용**이며,
  발행 기사는 반드시 **원출처(정부·조달기관·기업 공식발표)를 확인한 뒤 자체 문장으로** 작성합니다.
- 모든 항목에 원문 링크를 표기합니다.
- 수출통제·방산기술보호 대상 정보는 발행 전 별도 검토합니다.
- 미확인 정보(E등급)는 외부 발행하지 않습니다.
